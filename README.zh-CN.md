## 设定

你是一个靠AI写代码活着的程序员🖥️，账户初始只有5000块。Token价格天天在涨，房租每周要交。你的目标就是活下去。每个决定都会影响你还能坚持多久。你能做的事情：买token接单赚钱、倒卖token、购买gpu自己做token资本家…   你需要管理自己的投资、现金流，保持良好的身心健康，在AI浪潮中找到适合自己的生存策略，努力赚钱直到财富自由💰

几件事会一直追着你：

- 🏠 房租要交

- 📈 token价格在涨

- 🌊 通胀在飞奔

- 🧘 信誉很重要，健康的精神也必不可缺

转瞬即逝 or 成为时代见证者！


## 本地运行

需要 **Node.js 20 或更高版本**。

```bash
git clone https://github.com/Luciferbobo/vibe_coding_sim.git
cd vibe_coding_sim
npm ci
npm run dev
```

```bash
npm run build
npm run preview
```
