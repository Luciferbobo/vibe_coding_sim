## Intro

你是一名靠 AI 编写代码谋生的程序员，账户里只有 5,000 元。Token 行情不断波动，房租每七天准时到期。你要在资金耗尽前找到活下去的办法；如果经营得当，也许还能攒够财富，一键退休。

你可以购买 Token 接单赚钱、低买高卖赚取差价，也可以投资 GPU、持续产出 Token，打造自己的算力生意。

AI 浪潮袭来，你会被时代淘汰，还是逐步摸索出适合自己的生存策略，成为这场变革的见证者？

- 🏠 房租每七天到期，记得留好现金
- 📈 Token 市场瞬息万变，买卖时机很重要
- 🌊 通胀不断累积，今天的收入未必够明天生活
- ⭐ 信誉会影响接单机会
- 🧘 精神状态同样重要，别让自己先撑不住

## Local Deployment

Need Node.js 20+。

```bash
git clone https://github.com/Luciferbobo/vibe_coding_sim.git
cd vibe_coding_sim
npm ci
npm run dev
npm run build
```

React · TypeScript · Vite · Zustand
