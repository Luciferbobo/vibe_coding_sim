## 这是一个怎样的游戏？

你是一名靠 AI 编写代码谋生的程序员，账户里只有 **5,000 元**。Token 行情不断变化，房租每七天准时到期。你需要安排现金、挑选模型、完成订单，找到自己的生存策略。

你可以购买 Token 接单赚钱，也可以低买高卖赚取差价；攒下资本后，还能投资 GPU、产出 Token，建立自己的算力生意。经营得当，就有机会一键退休。

## 你要面对的挑战

- 🏠 **房租**：每七天交一次，记得预留现金。
- 📈 **Token 行情**：价格起伏不定，买入和卖出的时机都很重要。
- 🌊 **通胀**：成本不断变化，手头的钱未必一直够用。
- ⭐ **信誉**：影响你承接工作的能力，也需要用心经营。
- 🧘 **精神状态**：健康和精力同样是生存资源。

## 在线试玩

无需安装，打开网页即可开始：**[开始游戏 →](https://thatbobo.com/vibe_coding_sim/)**

## 本地运行

需要 Node.js 20 或更高版本。

```bash
git clone https://github.com/Luciferbobo/vibe_coding_sim.git
cd vibe_coding_sim
npm ci
npm run dev
```

构建生产版本：

```bash
npm run build
```
